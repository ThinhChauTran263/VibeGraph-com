VibeGraph CLI & MCP

Dành cho người dùng và AI assistant. Không gửi API key hoặc password vào cuộc trò chuyện. AI không được bịa endpoint, project ID, credit hay kết quả phân tích.

1. Cài CLI

Người dùng mới

npm install -g vibegraph-cli
vibegraph --version
vibegraph config set-url https://api.vibegraph.tech
vibegraph login
vibegraph key status

vibegraph login mở trình duyệt để đăng nhập và chọn project key thuộc tài khoản.

Cập nhật bản cũ

npm uninstall -g vibegraph-cli
npm install -g vibegraph-cli@latest
vibegraph --version

2. Chọn project và kiểm tra

vibegraph key list
vibegraph key change
vibegraph key status
vibegraph doctor

Key xác định project đang dùng. Các lệnh project-scoped bình thường tự nhận project được bind với key.

3. CLI Push

cd <LOCAL_PROJECT_FOLDER>
vibegraph push --dry-run
vibegraph push
vibegraph watch
vibegraph projects analyze
vibegraph projects status

Trong interactive shell vibegraph>, chỉ nhập push, doctor hoặc key status.

4. Các cách import

  • Dashboard archive: .zip, .tar, .tar.gz, .tgz.
  • Dashboard GitHub: repository public qua URL HTTPS, branch là tùy chọn.
  • Backend path: vibegraph projects create --path <backendPath>.

5. Cài MCP tự động

vibegraph mcp install cursor
vibegraph mcp install vscode
vibegraph mcp install generic --path ./mcp.json
vibegraph mcp doctor

Restart hoặc reload MCP server trong IDE sau khi cài.

6. Cài MCP thủ công

Để CLI sinh JSON stdio

vibegraph mcp config cursor
vibegraph mcp config vscode
vibegraph mcp config generic

Copy toàn bộ object được sinh ra. Không copy đường dẫn Windows của máy người khác.

Streamable HTTP

{
  "mcpServers": {
    "vibegraph": {
      "url": "https://api.vibegraph.tech/mcp",
      "transport": "streamable-http",
      "headers": { "X-API-Key": "<PROJECT_API_KEY>" }
    }
  }
}

Thay key bằng project API key active, không commit key và không lồng thêm object mcpServers.

7. Chẩn đoán MCP

vibegraph mcp doctor
  1. Doctor kiểm tra initialize và tools/list.
  2. Reload MCP server trong IDE.
  3. Kiểm tra tool xuất hiện và gọi list_projects.

8. Lỗi thường gặp

MCP key không hợp lệ

vibegraph key change
vibegraph mcp doctor

projects list trả HTTP 401

vibegraph login --email <email> --password <password>
vibegraph projects list

Người dùng tự nhập password trong terminal; không gửi password cho AI.

9. Checklist dành cho AI

  1. Hỏi OS và IDE/MCP client.
  2. Hỏi người dùng muốn CLI Push, MCP hay cả hai.
  3. Yêu cầu output đã che secret của vibegraph doctor và vibegraph mcp doctor.
  4. Hướng dẫn từng lệnh và chờ kết quả, không giả định thành công.
