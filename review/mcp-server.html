MCP Server — 15 tools cho AI agent

VibeGraph expose graph qua Model Context Protocol (Spring AI, Streamable HTTP tại /mcp), để AI agent (Claude, Cursor, Kiro…) truy vấn cấu trúc, trace flow & đánh giá impact ngay trong editor. Log khởi động xác nhận Registered tools: 15.

Mục tiêu review

  • Server MCP khởi tạo đủ 15 tool; kết nối được từ MCP client.
  • Mỗi tool trả dữ liệu đúng & grounded theo graph của project.
  • Tool đọc source tôn trọng allow-list & redaction.

Tiền điều kiện & cách kết nối

Backend chạy (MCP endpoint /mcp, protocol STREAMABLE). Cấu hình MCP client trỏ tới server VibeGraph. Ví dụ khối cấu hình:

{
  "mcpServers": {
    "vibegraph": {
      "url": "http://localhost:8080/mcp"
    }
  }
}

Luồng hoạt động của code

  • Đăng ký: các lớp mcp/tool/*Tool.java gắn @Tool; Spring AI MCP auto-config quét & đăng ký (log "Registered tools: 15").
  • Thực thi: tool gọi mcp/service (Analyzer/Service) → đọc graph qua graph/repository (Neo4j) & nguồn mcp/source (đọc file redact).
  • Transport: Streamable HTTP tại /mcp (cấu hình spring.ai.mcp.server).
