Graph Canvas (Sigma.js)

Khu vực trung tâm /projects/:id/graph: đồ thị force-directed render WebGL (Sigma.js + Graphology). Không có "option UI" dạng dropdown, nhưng hành vi được điều khiển bởi nhiều tham số cấu hình (env VITE_*) — phần dưới liệt kê giá trị mặc định cụ thể.

Hiển thị nhãn theo mức zoom (camera ratio)

Ratio THẤP = zoom vào gần. Mật độ nhãn đổi theo ngưỡng (lib/focusMode.ts):

Camera ratioMật độHiện gì
> 1.05minimalChỉ nhãn node đang chọn (forced).
0.7 – 1.05nodesNhãn node hiện theo ngưỡng kích thước.
≤ 0.7edgesNhãn loại cạnh (CALLS, DEFINES…) xuất hiện.

Ngoài ra Sigma chỉ vẽ nhãn khi node đạt kích thước hiển thị ≥ SIGMA_LABEL_RENDERED_SIZE_THRESHOLD = 15px (progressive reveal). Nút "Edge labels: On/Off" ép bật/tắt nhãn cạnh (xem thêm ở phần Search/Node Detail).

Safe Mode — cap đồ thị lớn

Khi số node (sau lọc) vượt GRAPH_SAFE_NODE_LIMIT = 1500, chỉ giữ node "ý nghĩa nhất" để render (lib/graphCap.ts). Thứ tự ưu tiên giữ lại:

  • 1. Ưu tiên theo loại: Project(100) > Package(90) > File(80) > Class/Interface(70) > Enum/Record/DBModel(65) > Route/APIEndpoint(60) > Method/Constructor(40) > Field(20) > Annotation(15) > External(10) > LocalVariable(5).
  • 2. Bậc (degree): node kết nối nhiều hơn (trung tâm hơn) thắng.
  • 3. id: quyết định cuối để ổn định/tái lập.
  • Cạnh chỉ giữ khi cả hai đầu còn lại. Toàn bộ graph gốc vẫn ở store (Legend/Show all); chỉ phần đưa vào Sigma bị bound. renderInfo.truncated=true → banner Safe Mode.

Backend cũng cap payload HTTP: vibegraph.graph.node-limit=1500, edge-limit=4000 (trần max 10000/30000) — trả kèm meta.truncated.

Luồng hoạt động của code

  • View: GraphView.vue (tab Graph/Diagrams) → GraphCanvas.vue.
  • Tải: useGraphData.ts → GET /api/projects/{id}/graph → store; graphCap.ts cap → graphAdapter.ts (apiToGraphology, màu/size theo loại).
  • Render: useSigma.ts tạo Sigma, applyCachedLayout (cache vị trí, FA2 400 vòng khi có node mới), gắn handler click/drag/pan/zoom, ghost layer (ghostLayer.ts + focusMode.ts).
  • Expand: double-click → useGraphExpand.ts → GET /graph/neighbors/{nodeId} (cap 500) → merge store → rebuild.
