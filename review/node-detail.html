Node Detail — Chi tiết node

Panel bên phải khi chọn 1 node. Gồm: header (tên + loại + FQN + file:line), danh sách quan hệ Incoming/Outgoing, nút xem source. Mỗi quan hệ có 2 mức tương tác: hover = preview, click = pin (ghim).

Các tương tác & hành vi cụ thể

Thao tácHành vi
Chọn nodeHiện tên, loại, FQN, đường dẫn file, dòng. FQN chỉ hiện khi khác filePath (tránh lặp với node File).
Hover 1 quan hệPreview (ưu tiên cao nhất): canvas làm nổi cạnh + node đối tác, KHÔNG đổi selection. Rời chuột → tắt preview.
Click 1 quan hệPin: ghim cạnh đó, giữ nổi bật kể cả khi rời chuột; item giữ style "selected" (pinnedEdgeId). KHÔNG điều hướng sang node đối tác.
Bấm "View source"Mở Code Viewer Modal đúng file & dòng.
Đóng panelBỏ chọn + thoát focus + gỡ pin.

Thứ tự ưu tiên focus (khi nhiều tín hiệu cùng lúc)

GraphCanvas.applyFocusReducers quyết định canvas làm nổi gì theo thứ tự:

  • 1. hoveredRelation (đang hover 1 quan hệ trong panel) — preview tạm.
  • 2. pinnedRelation (đã click ghim) — dính, chỉ mất khi click quan hệ khác / click node / bỏ chọn.
  • 3. hoveredGraphNode (hover node trên canvas).
  • 3.5. activeFlow (đang xem 1 Data Flow).
  • 4. selectedNode (node đang chọn).
  • 5. mặc định (không focus) — view graph đầy đủ.

Giới hạn hiển thị & che dữ liệu nhạy cảm

Hằng số (env)Mặc địnhÝ nghĩa
NODE_DETAIL_MAX_PROPERTIES12Số property tối đa hiển thị (còn lại thu gọn).
NODE_DETAIL_MAX_CONNECTIONS50Số connection tối đa mỗi chiều (incoming / outgoing).
Che property nhạy cảm: giá trị có key khớp regex /(secret|token|password|credential|auth|api[_-]?key|private[_-]?key)/i bị ẩn/che. Review cần thử node có property loại này để xác nhận không lộ giá trị.

Luồng hoạt động của code

  • UI: NodeDetailPanel.vue đọc selectedNode + filteredGraphData (useGraphData.ts), dựng connection từ các cạnh chạm node (map nodeById).
  • Focus/pin: phát relationHover/relationSelect → GraphCanvas cập nhật hoveredRelation/pinnedRelation → applyFocusReducers (thứ tự ưu tiên ở trên) + lib/focusMode.ts.
  • Xem source: CodeViewerModal.vue (useSourceCode.ts → GET /api/projects/{id}/source).
