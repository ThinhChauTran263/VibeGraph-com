Import Archive (tải lên gói nén)

Tải lên một gói nén dự án Java (.zip, .tar, .tar.gz, .tgz). Backend giải nén vào workspace tạm rồi phân tích. Phù hợp khi mã nguồn không nằm trên máy chủ.

Mục tiêu review

  • Chọn/kéo-thả file hợp lệ → upload + phân tích → mở graph.
  • Chặn file sai định dạng & file vượt giới hạn dung lượng (mặc định 100MB).
  • Tiến độ & xử lý lỗi rõ ràng.

Tiền điều kiện

Neo4j + Backend + Web client chạy. Có sẵn 1 file nén dự án Java để thử (ví dụ nén thư mục asm-j6).

Kịch bản thao tác

# Thao tác Kết quả kỳ vọng P/F
1 Dashboard → tab "Archive" Hiện vùng chọn file & mô tả định dạng cho phép.
2 Chọn 1 file .zip dự án Java hợp lệ, đặt tên, Import Upload chạy, trạng thái importing + tiến độ.
3 Chờ hoàn tất Điều hướng sang graph của project mới.
4 Thử chọn file sai định dạng (.pdf) Bị chặn/từ chối với thông báo rõ ràng.
5 Thử file > 100MB (nếu có) Bị chặn theo giới hạn dung lượng.
Ghi chú: Giới hạn dung lượng & đường dẫn bỏ qua (target, .git, node_modules…) cấu hình ở application.yaml mục vibegraph.import.archive và multipart spring.servlet.multipart.

Tham số & ràng buộc cụ thể

Ràng buộc Giá trị Nguồn
Định dạng chấp nhận .zip · .tar.gz · .tgz · .tar ARCHIVE_ALLOWED_EXTENSIONS (gán vào accept=)
Dung lượng tối đa (client) 100 MB VITE_ARCHIVE_MAX_SIZE_MB
Multipart (backend) file 100MB · request 105MB spring.servlet.multipart
Bỏ qua khi giải nén target, build, .git, .idea, node_modules vibegraph.import.archive.ignored-paths
Poll / stall / absolute timeout 1000ms / 5 phút / 1 giờ runtimeConfig (dùng chung import)

Validate phía client theo thứ tự: đuôi file → file rỗng → dung lượng (validateArchiveFile), mỗi lỗi có thông điệp riêng. Backend vẫn re-validate.

Ngóc ngách backend & bảo mật

  • Nhận diện type theo ĐUÔI TÊN (không theo Content-Type). Sai đuôi → 400 UNSUPPORTED_TYPE; file zip đổi tên .tar → lỗi EXTRACTION_FAILED lúc giải nén.
  • Chỉ ghi file .java; bỏ ignoredPaths (target/build/.git/.idea/node_modules). Không có .java → EMPTY_ARCHIVE.
  • Chống archive-bomb: kiểm size trước giải nén VÀ copyCapped đếm tổng byte đã giải nén (dừng khi vượt) → OVERSIZE.
  • Chống path traversal (resolveSafely): loại path tuyệt đối, ổ đĩa Windows, segment .., hoặc target thoát khỏi destRoot → UNSAFE_ENTRY. TAR symlink/hardlink/non-regular bị từ chối.
  • Workspace = ${tmpdir}/vibegraph/uploads/<uuid>; đăng ký qua validateWorkspacePath (giới hạn trong workspace, không dùng allowed-root).
Reviewer soi: Cleanup file tạm là best-effort — JVM chết giữa chừng → workspace mồ côi (không có sweeper dọn stale). Async fail giữ project FAILED nhưng xoá source workspace → re-analyze sau sẽ fail. Không có auth (xem chung).

Điểm cần soi

  • Giới hạn multipart (max-file-size 100MB, max-request 105MB) khớp giới hạn nghiệp vụ.
  • Workspace giải nén là thư mục ghi được (không phải mount chỉ-đọc).
  • Không giải nén nhầm thư mục rác (target/build/.git…).
  • Xử lý zip lỗi/không phải Java: báo lỗi thay vì treo.

Luồng hoạt động của code

  • UI: ImportProjectPanel.vue → AddProjectArchive.vue (chọn file, hiển thị tiến độ).
  • Composable: useArchiveImport.ts + lib/archiveUpload.ts (upload multipart, theo dõi tiến độ), trạng thái phân tích qua WebSocket/poll.
  • HTTP: POST /api/projects/import-archive (multipart: name + file).
  • Backend: ImportController.importArchive() → dịch vụ import archive giải nén vào workspace tạm (ArchiveImportProperties) → parser phân tích nền → lưu Neo4j; tiến độ phát qua topic status.
