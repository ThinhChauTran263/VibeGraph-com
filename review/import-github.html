Import GitHub

Dán URL HTTPS của một repo GitHub công khai; backend tải tarball, giải nén và index. Không cần clone thủ công.

Mục tiêu review

  • URL hợp lệ → tải & phân tích → mở graph.
  • Chặn URL sai định dạng / repo private / repo không tồn tại với thông báo rõ.
  • Có timeout hợp lý cho preflight & tải tarball.

Tiền điều kiện

Neo4j + Backend + Web client chạy; máy chủ có mạng ra Internet tới GitHub.

Chỉ chấp nhận HTTPS + host github.com. Thông điệp lỗi hiển thị nguyên văn khi khớp mẫu an toàn (public / private / not found / too large / rate limit / must match / still analyzing…); lỗi mạng (backend down) → "Cannot reach the server…"; còn lại → thông điệp chung "Verify the repository is public".

Ngóc ngách backend & bảo mật

  • Chặn host: GitHubUrlParser ép scheme https + host github.com + đúng 2 segment owner/repo. Chỉ repo public.
  • Preflight GET api.github.com/repos/{o}/{r}: 404 → "not found/not public", 403 → "rate limiting", private:true → từ chối, size(KB) > max → oversize; lấy default_branch làm ref.
  • Tải tarball /tarball/{ref} stream ra file, copyCapped dừng khi vượt 100MB. Giải nén dùng chung ArchiveExtractor (cùng guard traversal/symlink/bomb).
  • Timeout: connect 10s / preflight 20s / tarball 60s. InterruptedException re-interrupt + throw.
  • Lỗi → 422 (GithubImportException).
Reviewer soi: ImportController.importGithub chạy parse URL + preflight + download+giải nén+đăng ký ĐỒNG BỘ trên request thread, chỉ phần analyze mới offload → thời gian tải chặn phản hồi 202. HttpClient follow redirect NORMAL — 3xx từ api.github.com có thể redirect fetch tarball sang host khác (codeload/CDN là mong đợi, nhưng target redirect không được re-validate theo allowlist). Không auth token nên chỉ public.

Điểm cần soi

  • Validate URL phía FE trước khi gửi (chỉ HTTPS, đúng host GitHub).
  • Timeout connect/preflight/tarball đúng cấu hình vibegraph.import.github.
  • Thông báo lỗi phân biệt: sai URL vs không tồn tại vs mạng lỗi.

Luồng hoạt động của code

  • UI: ImportProjectPanel.vue → GitHubImportForm.vue.
  • Composable: useGitHubImport.ts validate URL, gọi API, theo dõi tiến độ (WebSocket/poll).
  • HTTP: POST /api/projects/import-github (body: URL repo).
  • Backend: ImportController.importGithub() → dịch vụ import GitHub tải tarball (timeout theo GitHubImportProperties) → giải nén → parser phân tích → lưu Neo4j; tiến độ phát qua topic status.
