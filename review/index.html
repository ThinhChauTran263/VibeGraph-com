Bộ kịch bản Review — Giai đoạn 1

Tài liệu review từng tính năng của VibeGraph theo luồng người dùng: Trang chủ → Dashboard → Graph → Diagrams → API/MCP. Mỗi tính năng là một file HTML riêng gồm: mục tiêu, kịch bản thao tác (có bảng bước & kỳ vọng), điểm cần soi, và luồng hoạt động của code + file liên quan.

Cách dùng: Mở lần lượt từng file .html trong thư mục review/ bằng trình duyệt. Người review UI đọc phần "Kịch bản thao tác"; người review code đọc phần "Luồng hoạt động của code" & "File liên quan".

0. Chuẩn bị môi trường (bắt buộc trước khi review)

VibeGraph gồm 3 thành phần phải chạy đồng thời: Neo4j (DB đồ thị) → Backend Spring Boot (:8080) → Web client Vite (:5173).

# 1) Khởi động Neo4j (Docker) — NẾU backend báo "Unable to connect to localhost:7687"
docker start vibegraph-neo4j
#   (lần đầu chưa có container:  docker compose up -d neo4j)

# 2) Backend Spring Boot (Java 21) — cổng 8080
./mvnw spring-boot:run          # Windows: .\mvnw.cmd spring-boot:run

# 3) Web client — cổng 5173
cd vibegraph-web ; npm install ; npm run dev
Bẫy thường gặp: Backend sẽ tắt ngay nếu Neo4j chưa sẵn sàng (lỗi Neo4j schema migration failed). Luôn chờ Neo4j "READY" (mở được http://localhost:7474) rồi mới chạy backend.
