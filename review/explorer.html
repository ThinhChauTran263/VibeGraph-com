Explorer — Cây file nguồn

Tab đầu tiên của sidebar trái. Dựng cây thư mục/mã nguồn từ dữ liệu graph (node loại File), cho phép tìm file & click để focus node đại diện trên canvas.

Mục tiêu review

  • Cây phản ánh đúng cấu trúc thư mục dự án.
  • Tìm file lọc cây & tự mở nhánh chứa kết quả.
  • Click file → focus/di chuyển tới node tương ứng trên graph.

Kịch bản thao tác

#Thao tácKết quả kỳ vọngP/F
1Sidebar → tab "Explorer"Cây file hiển thị, mặc định mở các nhánh; chân panel ghi tổng số file.

Thuật toán dựng cây & ngóc ngách (fileTree.ts)

  • Gom file: mỗi filePath phân biệt = 1 file; khi nhiều node cùng path, giữ node đại diện theo ưu tiên File > Class > Interface > Enum > Record > DBModel. Node không có filePath bị loại (Method/Field thuần không path sẽ không xuất hiện).
  • Rebase root: nếu có node Project → dùng properties.path làm gốc & name làm nhãn; nếu không → cắt prefix thư mục chung dài nhất (tránh lộ đường dẫn máy D:/Users/.../uploads). So sánh lowercase để chịu khác biệt hoa/thường ổ đĩa Windows.
  • Sort: folder trước file; cùng loại sort alphabet không phân biệt hoa/thường, có số tự nhiên (kiểu IDE).
  • Tìm kiếm: file giữ nếu tên HOẶC full path chứa term; folder giữ nếu có con khớp HOẶC tên folder khớp — khi folder tự khớp thì giữ toàn bộ con (kể cả không khớp).
Ngóc ngách reviewer: ExplorerPanel mặc định mở tất cả folder và watch(allFolderPaths, immediate) reset lại mỗi khi graph đổi tham chiếu → với realtime/FULL_UPDATE, trạng thái collapse của user bị mất. Vì mở sẵn hết nên tính năng "auto-mở nhánh khớp" gần như thừa (chỉ có ý nghĩa khi user đã tự collapse). Cây chưa hỗ trợ điều hướng bằng phím mũi tên (a11y).

Điểm cần soi

  • Explorer dùng graph gốc (graphData) chứ không phải dữ liệu đã lọc, nên cây luôn đầy đủ.
  • Node được resolve từ toàn bộ node, kể cả node đang bị filter ẩn.
  • Cây sync lại khi đổi project.

Luồng hoạt động của code

  • UI: ExplorerPanel.vue + ExplorerTreeNode.vue (đệ quy cây).
  • Dựng cây: lib/fileTree.ts chuyển danh sách node File thành cấu trúc thư mục; tìm kiếm lọc + đánh dấu nhánh cần mở.
  • Focus: click file phát sự kiện select(nodeId) lên GraphCanvas.vue → onExplorerSelect resolve node trong graphData.value.nodes (graph đầy đủ) → selectNode + applyFocusReducers.
