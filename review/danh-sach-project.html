Danh sách Project đã import

Khu vực bên phải Dashboard liệt kê mọi project đã import: mở để xem graph, xóa từng project, Clear all, Refresh, và tự động cập nhật trạng thái ANALYZING → ANALYZED.

Mục tiêu review

  • Danh sách tải đúng, mở được project → vào graph.
  • Xóa 1 project, Clear all (có xác nhận), Refresh hoạt động.
  • Project đang phân tích tự cập nhật trạng thái mà không cần F5.

Tiền điều kiện

Backend + Neo4j chạy; đã có ít nhất 1 project import trước đó.

Kịch bản thao tác

#Thao tácKết quả kỳ vọngP/F
1Mở /dashboardKhối "Imported projects" liệt kê project kèm nhãn trạng thái (ANALYZED/ANALYZING).
2Bấm 1 project ANALYZEDĐiều hướng /projects/:id/graph, graph tải.
3Bấm RefreshDanh sách nạp lại từ backend.
4Import 1 project mới, quay lại danh sách (không F5)Trạng thái tự chuyển ANALYZING → ANALYZED nhờ auto-refresh nền.
5Bấm Delete 1 projectProject biến mất khỏi danh sách; backend xóa dữ liệu graph tương ứng.
6Bấm Clear allHộp xác nhận hiện; xác nhận → xóa toàn bộ.
Thao tác phá hủy: Delete & Clear all xóa dữ liệu graph khỏi Neo4j, không hoàn tác. Review cần xác nhận có bước xác nhận (Clear all đã có window.confirm) và thông báo lỗi khi xóa thất bại.

Tham số cụ thể

Nhịp auto-refresh nền: PROJECTS_AUTO_REFRESH_INTERVAL_MS = 5000ms (env VITE_PROJECTS_AUTO_REFRESH_INTERVAL_MS). Tạm dừng khi tab ẩn (document.hidden); không nháy "Loading…" và không đè lỗi đang hiển thị. Clear all có window.confirm và xóa tuần tự theo snapshot id.

Điểm cần soi

  • Auto-refresh nền không nháy "Loading…" và không đè lỗi người dùng đang đọc.
  • Tab ẩn (document.hidden) thì tạm dừng auto-refresh (tiết kiệm request).
  • Clear all xóa tuần tự, báo lỗi nếu vài project không xóa được.

Luồng hoạt động của code

  • UI: views/HomeView.vue render danh sách + nút Open/Delete/Clear all/Refresh; auto-refresh bằng setInterval (gated theo document.hidden).
  • HTTP: projectApi.list() → GET /api/projects; projectApi.remove(id) → DELETE /api/projects/{id}.
  • Backend: ProjectController (list/get/delete) → ProjectService đọc/xóa qua graph/repository (Neo4j).
  • Mở project: lưu currentProjectId/projectName vào stores/project.ts rồi router.push sang route graph.
