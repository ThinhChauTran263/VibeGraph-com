REST API

Tầng HTTP phục vụ web client. Mọi response bọc trong ApiResponse<T> = { success, data, error }. Base: http://localhost:8080.

Mục tiêu review

  • Các endpoint trả đúng cấu trúc & mã lỗi hợp lý.
  • Guardrail payload graph (cap node/edge) hoạt động.
  • CORS & xử lý lỗi tập trung (GlobalExceptionHandler).

Kịch bản kiểm thử nhanh (curl / trình duyệt)

# Health
curl http://localhost:8080/actuator/health

# Danh sách project
curl http://localhost:8080/api/projects

# Graph (thay :id bằng projectId thật)
curl "http://localhost:8080/api/projects/<id>/graph"

# Impact analysis
curl "http://localhost:8080/api/projects/<id>/graph/impact?nodeId=<nodeId>&depth=1&profile=dependency"
Chưa có auth: API hiện không có xác thực/ủy quyền — phù hợp môi trường dev cục bộ, nhưng khi triển khai cần bổ sung. Đặc biệt /browse & /source đọc file máy chủ: cần allowed-root + allow-list + redaction.

Điểm cần soi

  • Guardrail vibegraph.graph.node-limit/edge-limit áp cho payload graph; response có meta.truncated.
  • CORS chỉ mở cho localhost:5173/3000 (không wildcard kèm credentials).
  • Lỗi trả về chuẩn hóa qua GlobalExceptionHandler, không lộ stack trace.
  • Response không chứa dữ liệu nhạy cảm (source được redact).

Luồng hoạt động của code

  • Client: vibegraph-web/src/lib/api.ts gói mọi lời gọi; kết quả unwrap từ ApiResponse.
  • Controller: graph/controller/*, diagram/controller/* nhận request, validate, gọi service.
  • Service: graph/service, diagram/service, graph/importer xử lý nghiệp vụ; đọc/ghi Neo4j qua graph/repository.
  • Cross-cutting: common/exception/GlobalExceptionHandler (lỗi), common/config (CORS, Neo4j migration), common/dto/ApiResponse.
