Code Viewer — Xem mã nguồn

Modal chỉ-đọc xem source của file gắn với node. Tải theo cửa sổ dòng (mặc định 300 dòng/lần), highlight bằng highlight.js nạp lười, có nút Copy & Load more. Teleport ra body: desktop = panel giữa, mobile = sheet toàn màn.

Hành vi cụ thể

Cơ chếChi tiết
Cửa sổ dòngWINDOW_LINES = 300. Lần đầu tải dòng 1–300; "Load more" nạp cửa sổ kế tiếp và append.
Còn dòng để tải?hasMore = found && loadedToLine < totalLines → quyết định hiện nút Load more.
HighlightMap ngôn ngữ → grammar highlight.js: java, kotlin, xml, yaml, sql, properties, markdown, gradle. Ngôn ngữ ngoài danh sách → render plain text đã escape (không đoán sai grammar).
Không phục vụ đượcfound=false → hiện notServedReason (ngoài allow-list, file nhị phân…) thay vì lỗi trần.
Chống raceToken seq + activePath: phản hồi trễ của file trước bị bỏ.
Cảnh báowarnings[] từ backend (vd đã redact) được hiển thị.
Bảo mật/riêng tư: Backend đọc file giới hạn cửa sổ dòng + redact nội dung nhạy cảm, chỉ phục vụ file trong project source root/allow-list (SourceFileService, dùng chung module mcp/source). Review cần thử mở file ngoài phạm vi → phải bị chặn.

Điểm cần soi

  • highlight.js nạp lười (dynamic import) — không nằm trong bundle khởi tạo.
  • Không tải nguyên file khổng lồ — luôn theo cửa sổ 300 dòng.
  • notServedReason & warnings được hiển thị; giá trị nhạy cảm đã redact.

Luồng hoạt động của code

  • UI: CodeViewerModal.vue (mở từ Node Detail hoặc node ảnh hưởng trong Impact).
  • Composable: useSourceCode.ts — load() (dòng 1..300), loadMore() (append), state found/hasMore/notServedReason/warnings, token chống race.
  • HTTP: GET /api/projects/{id}/source?path=&startLine=&endLine=.
  • Backend: SourceController.getSource() → SourceFileService (module mcp/source) cắt cửa sổ dòng + redact + trả metadata.
