Class Diagram

Sinh sơ đồ lớp Mermaid từ graph (ClassDiagramServiceImpl.generateClassDiagram(projectId, packageFilter)).

Lấy classifier & thành viên

  • Classifier: chỉ Class, Interface, Enum (CLASSIFIER_TYPES). (Lưu ý: DBModel là label riêng ở graph — reviewer cần kiểm DBModel có nằm trong tập này không tuỳ mapping.)
  • Method qua HAS_METHOD: visibility marker + tên + params + return; Field qua HAS_FIELD. Dùng TreeSet (deterministic + dedupe overload).
  • Visibility: public +, private -, protected #, else ~.
  • Stereotype: Interface «interface», Enum «enumeration», class abstract «abstract», else springLayer → «LAYER» nếu khác NONE.

Quan hệ → ký hiệu Mermaid

Edge graphMermaidNhãn
EXTENDS--|>extends
IMPLEMENTS..|>implements
INJECTS-->uses

Các edge khác bị bỏ qua. Edge chỉ giữ khi CẢ 2 đầu nằm trong tập đã chọn/lọc. TYPE_OF (association theo kiểu field) cố ý bỏ để sơ đồ gọn.

Lọc package & danh sách package

  • matchesPackage: filter rỗng = tất cả; else pkg == filter || pkg.startsWith(filter + "."). packageOf = phần trước dấu . cuối của fullName.
  • availablePackages: tính trên TOÀN BỘ classifier (không phụ thuộc filter), TreeSet sorted → chip pick-list.
  • Trạng thái rỗng: sinh classDiagram hợp lệ với comment %% No classes detected.
⚠ Ngóc ngách reviewer cần biết:
  • Cap MAX_CLASSES = 50 (deterministic theo fullName), cắt âm thầm (chỉ log.debug). Quan hệ tới class bị cắt sẽ biến mất (edge lọc khi 1 đầu không trong tập) → sơ đồ có thể trông thiếu kết nối mà không có cảnh báo cho user.
  • availablePackages dùng heuristic dấu chấm cuối; classifier không package (blank) bị bỏ; tên lồng $ không xử lý riêng.
  • INJECTS vẽ như association --> giữa 2 classifier, không phải association theo field.
