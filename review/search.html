Search — Tìm node trong graph

Ô tìm kiếm nổi trên canvas: gõ để tìm node theo tên, chọn kết quả để chọn & điều hướng tới node đó.

Kịch bản thao tác

#Thao tácKết quả kỳ vọngP/F
1Gõ tên node (vd UserService)Danh sách gợi ý khớp hiển thị.
2Chọn 1 kết quảNode được chọn, panel chi tiết mở, canvas focus/điều hướng tới node.
3Bấm ClearXóa lựa chọn, phát sự kiện bỏ chọn.
4Tìm chuỗi không khớpKhông có gợi ý; không lỗi.
5Tìm node đang bị filter ẩnKết quả dựa trên tập node đang hiển thị (nodes đã lọc) — xác nhận hành vi mong muốn.

Tham số cụ thể

Số gợi ý tối đa: SEARCH_SUGGESTIONS_LIMIT = 8 (env VITE_SEARCH_SUGGESTIONS_LIMIT). Tìm trên tập nodes đã lọc, khớp theo tên.

Điểm cần soi

  • Search chạy trên nodes (dữ liệu đã lọc) — khác Explorer (dùng graph gốc). Cần thống nhất kỳ vọng với team.
  • Bàn phím: điều hướng gợi ý & Enter chọn hoạt động (a11y).

Luồng hoạt động của code

  • UI: components/graph/SearchBar.vue nhận prop nodes, phát select(node) / clear.
  • Xử lý: GraphCanvas.vue → onSearchSelect gọi selectNode + applyFocusReducers; onSearchClear → clearSelection.
  • Điều hướng canvas: dùng focusNode của useSigma.ts để center node.
