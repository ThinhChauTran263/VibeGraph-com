## Current QA notes

**Ghi chú kỹ thuật còn hiệu lực (audit 2026-08-14):**

- Impact Analysis supports `profile=dependency|structural|type-data-flow`. Default `dependency` keeps the original reverse blast-radius traversal (`CALLS|IMPORTS|EXTENDS|IMPLEMENTS|INJECTS`). `structural` uses containment/definition/route relationships for Package/File/APIEndpoint/Field-style nodes. `type-data-flow` uses type and CPG edges when present.
- Impact depth groups are now consistent: d=1 -> willBreak, d=2 -> likelyAffected, d>=3 -> mayNeedTesting. Depth 4/5 nodes are no longer counted in total without being listed.
- Focus Mode N-hop controls were removed after UX review; click/select highlight and manual graph navigation remain.
- Auth dùng **cookie HttpOnly** (không JWT trong localStorage). Blocked account trả `ACCOUNT_BLOCKED` trước `QUOTA_EXCEEDED`. Mã lỗi chuẩn: `ACCOUNT_BLOCKED`, `ACCOUNT_DEACTIVATED`, `FEATURE_DISABLED`, `QUOTA_EXCEEDED`, `CREDIT_EXHAUSTED`, `CONCURRENT_IMPORT_LIMIT`, `TOO_MANY_REQUESTS`, `IP_BLOCKED`, `API_KEYS_DISABLED`, `API_KEY_PLAN_LIMIT_REACHED`, `FORBIDDEN`.
- Realtime: graph + reports dùng **WebSocket/STOMP**; request events + audit logs dùng **SSE**. Không đổi kênh nếu chưa có quyết định mới.
- Class Diagram (Mermaid) đã **gỡ khỏi sản phẩm**; Use Case chuyển sang **SVG UML 2.5** + AI refine (Gemini failover, tắt được).
- Project delete hiện đi qua trash 3 ngày: `GET /api/projects/trash`, restore, purge ngay và scheduled retention sweep; chuyển vào trash chưa giải phóng quota, purge mới dọn extracted files/usage.
- Full-graph repository có Caffeine write-through snapshot cache (TTL 5 phút, tối đa 32 project snapshots); đây **không** phải content-hash skip unchanged files. Graph endpoint có node/edge caps nhưng chưa có offset/cursor pagination.
- Supabase realtime storage là implementation optional với safe disabled fallback; `VIBEGRAPH_SUPABASE_ENABLED` mặc định `false`, audit này không chứng minh production cutover.

| Title               | Mô tả ngắn gọn của PBI/User Story, thể hiện đúng ý định. Ví dụ: 'Import archive ZIP/TAR project Java'.                                                                                                                               |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Iteration           | Sprint mà PBI được thực hiện. Backlog reconciled hiện phân bố qua Sprint 1–4; dùng cột Sprint của từng dòng làm nguồn sự thật.                                                                                                      |
| Assigned To         | Năm thành viên: Thái (BA/PO/test), Thịnh (leader/PM), Khoa và Danh (fullstack), Vinh (backend/Scrum Master). Task chung giữ đúng tên assignee trong bảng.                                                                            |
| State               | Trạng thái PBI: New → Approved → Committed → In Progress → Done (hoặc Removed). Mặc định khởi tạo là 'New'. Bản FINAL dùng thêm 'In Progress' để phản ánh tiến độ realtime.                                                           |
| Business Value      | Giá trị nghiệp vụ: High / Medium / Low. Ưu tiên cao cho import, parser, Neo4j, graph visualization.                                                                                                                                  |
| Acceptance Criteria | Tiêu chí chấp nhận gồm cả thành công và thất bại, dạng 'Thành công: ...; Thất bại: ...'.                                                                                                                                             |

| Database            | **Data plane:** Neo4j 5.x qua raw Neo4j Java Driver, scoped by `projectId`, with 2 Cypher migrations (`V1`, `V2`). **Control plane:** PostgreSQL + Spring Data JPA + 19 Flyway SQL files (`V1–V15`, `V17–V20`; no V16) for auth/ownership/plan/credit/API key/audit/abuse. **Optional realtime store:** Supabase/PostgreSQL implementation with one migration, disabled by default and not proven cut over in production. |
| Cấm                 | Neo4j: KHÔNG dùng Spring Data Neo4j OGM hay entity @Node (chỉ raw Driver). KHÔNG dùng JPA cho graph. Postgres: JPA chỉ dùng cho control plane; schema do Flyway quản (`ddl-auto=validate`). KHÔNG hardcode giá credit trong code (đọc từ `credit_pricing_rules`). KHÔNG lưu secret/API key thô (chỉ BCrypt hash, hiển thị 1 lần). |
