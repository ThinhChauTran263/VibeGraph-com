Vấn đề

Vì sao AI viết code vẫn sai?

Năm 2026, AI sinh ra hơn 40% code mới. Nhưng AI không có bản đồ kiến trúc dự án. Nó như thợ xây không có bản vẽ.

01

AI viết sai pattern dự án

AI không biết dự án dùng layered architecture, Spring DI, hay event-driven. Nó tự đoán → 30% code phải sửa lại.

02

Onboarding mất 1-2 tuần

Dev mới phải đọc tay từng file để hiểu dự án. Càng nhiều file, càng lâu hiểu. Mất productivity nghiêm trọng.

03

Tài liệu luôn lỗi thời

Sơ đồ kiến trúc vẽ một lần rồi không ai cập nhật. Code đổi mỗi ngày, doc đứng yên. Niềm tin vào doc giảm dần.

04

Sửa 1 chỗ, vỡ 10 chỗ

Đổi một method → không biết bao nhiêu nơi đang gọi. Bug âm thầm lan ra production. Tốn giờ truy vết.

Giải pháp

VibeGraph = Google Maps cho mã nguồn

Tự động đọc code Java, dựng đồ thị tương tác, cập nhật real-time, và cung cấp context cho AI qua giao thức MCP mở.

Một bản đồ. Mọi người cùng nhìn.

Mỗi class, method, route, package biến thành một nút. Mỗi cuộc gọi hàm, mỗi import, mỗi quan hệ kế thừa biến thành một cạnh. Bạn có thể click, zoom, lọc, tìm kiếm.

  • Người đọc — onboarding 1 ngày thay vì 1 tuần
  • AI đọc — Cursor, Claude Code, Kiro hiểu kiến trúc qua MCP
  • Cập nhật real-time — lưu file, bản đồ thay đổi trong <3 giây
  • Phân tích ảnh hưởng — biết sửa method này sẽ vỡ những đâu
Controller Service Repository Method Endpoint Enum
Tính năng

9 khả năng cốt lõi sau 8 tuần

Mỗi tính năng đều có acceptance criteria rõ ràng. Không scope creep, không nice-to-have trá hình.

Java Parsing

JavaParser 3.26 + Symbol Solver. Parse 500 file < 30s. Detect Spring annotations, call graph chính xác > 85%.

Neo4j Graph DB

Lưu trữ đồ thị qua interface GraphRepository. Truy vấn 3-hop < 500ms. Schema strict, có constraints.

Force Graph (Sigma.js)

WebGL render 5000+ nodes 60fps. ForceAtlas2 layout trong Web Worker. 9 node types, 8 edge types phân màu.

UML Diagrams

Use Case + Class Diagram tự sinh từ source. Mermaid syntax, có thể export SVG/PNG. Cập nhật khi code đổi.

Realtime Update

Java WatchService + WebSocket STOMP. Save file → bản đồ thay đổi < 3s. Không reload, chỉ patch diff.

MCP Server

Spring AI MCP Boot Starter. 4 tools: architecture, class context, layer pattern, impact. Streamable HTTP.

GitHub Import

Paste URL public repo → backend clone shallow → analyze → trả về projectId. Auto cleanup sau 24h.

REST API + WebSocket

9 endpoints chuẩn REST. WebSocket STOMP push diff incremental. OpenAPI doc auto-generate.

Impact Analysis

Click vào method → thấy blast radius 5 hops. Cypher query qua APOC. Hiển thị mức risk trực quan.
